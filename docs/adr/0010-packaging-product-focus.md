# ADR-0010：当前产品收敛至包装行业

- 状态：Accepted
- 日期：2026-09-05
- 决策来源：产品负责人明确要求仅针对包装行业，不再支持家具。
- 替代：D9 与 M2 文档中同时支持 Print/Furniture 的产品范围；不改变 Agent Core 与 Enterprise Layer 的行业无关边界。

## 背景与决定

同时服务包装和家具扩大了需求字段、界面入口与验证范围。当前产品聚焦包装企业售前/跟单的需求整理，覆盖包装袋、纸盒、礼盒、包装罐、运输包装和包装标签，通过现有 Print Domain Pack 交付可确认、版本化和审批的需求单。

删除行业选择器、家具示例、家具必填字段及别名。新请求和模型输出只接受 `industry=print`，此标识继续代表包装 Domain Pack，以兼容既有包装记录。普通聊天的产品指令也聚焦包装。

API 在变更业务状态前检查既有 Run 的行业，拒绝将历史非包装 Run 重新标注为包装。旧行业工作区返回只读说明；Worker 不执行旧行业任务，旧 Job 到达时以不可重试错误停止。旧记录可取消或删除会话，但不能继续生成、修改 Fact、审批或使用当前包装导出接口。包装指标排除历史非包装 Run。

## 替代方案

- 仅隐藏家具按钮：不采用，API、Worker 和模型 Schema 仍会保留错误产品范围。
- 删除或自动转换历史记录：不采用，会破坏权威事实和历史交付的可追溯性。
- 将内部 `print` 改名为 `packaging` 并迁移存储：暂不采用，此次收敛无需变更已有包装 Run 的事实标识。

## 验证与影响

固定评测集升级为 `blackx-m2-packaging-workflow-baseline-v3`，保留 10 个任务、4 个可审批和 6 个需补充/确认路径，全部属于包装。旧跨行业评测和用户研究记录保持历史身份，不改写为包装专属验收证据。

增加新家具请求拒绝、非包装字段拒绝、历史 Run 不可转换、Worker 不执行和原始事实不被修改的离线回归。包装尺寸、材料、刀模、报价、认证等仍须权威来源或人工确认；本次收敛不新增生产文件或自动报价承诺。

## 迁移与退出条件

无破坏性数据迁移；原始消息、附件、交付版本及事件继续保留。重启本地 Host 并刷新浏览器后启用新入口与 API 约束。未来只有在包装真实用户闭环稳定、获得明确新行业需求并重新形成产品决策和独立评测后，才考虑恢复其他行业；不得通过 Agent Core 条件分支接入。
