# 会话删除验收 · 2026-09-05

本次补齐侧栏删除入口、原生确认弹窗、DELETE API、持久化删除标记和关联任务清理。没有对真实用户数据执行删除；浏览器操作和 HTTP 验收全部使用临时目录及本地固定 Provider。

## 行为与边界

- 删除前显示会话标题、停止任务范围和本地审计保留说明；支持取消、失败提示和重试。
- 删除非当前会话不清空当前草稿。删除当前会话选择相邻会话；删空后不自动创建新记录，重新打开页面仍为空，可主动新建。
- Session 原子写入删除标记及首次操作人/时间。重复删除保持相同结果；删除后不再列出，读取和续写被拒绝，迟到的模型结果不能重新显示或保存会话。
- 活动 Turn 被中止，关联队列中的 queued/leased Job 被取消，Cron 暂停，未完成 Workflow 通过状态机取消并使审批失效；已通过的 Artifact/Approval 保留原状态。
- 清理失败保留删除意图并返回明确的 `conversation_cleanup_pending`。Scheduler 在派发前后重试，覆盖进程中断和迟到 Outbox。清理不能成功时不继续领取新 Job。
- 工作台会话、附件下载、Trace、任务详情、需求单和导出入口拒绝已删除会话。历史消息、附件、上下文、交付物和审计记录仍保留在本地；本功能不是物理清除或数据保留期限管理。
- 用户主动取消/删除导致的中断不会把模型连接状态改为“最近请求失败”。
