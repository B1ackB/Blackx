# 即时文件审批验收（2026-09-05）

当前交互：用户直接提出文件任务，Agent 调用文件工具自动发起单次审批，显示具体绝对路径和改动；无需先添加目录。读取无需逐次审批，新建、修改和删除始终等待用户批准。设计见 [ADR-0013](../adr/0013-just-in-time-file-approval.md)。

## 自动验证

- `npm run check`：44 个测试文件、208 项测试通过，15 项需要显式启用的原生专项测试跳过；TypeScript 与 Vite 构建通过。
- `npm run eval:product`：固定本地 Anthropic Provider、真实 HTTP、Core Loop、审批 API 和操作系统文件系统。无目录预授权即可发起审批；批准前新文件不存在，批准后创建；外部原文修改后重新审批写入，历史备份保留；批准删除后原路径消失。旧目录授权/撤销 API 返回 410，未认证仍返回 403。原生 PDF 解析与业务审批、导出、取消、删除会话回归通过。
- 本地文件专项 9 项单测：真实读写删除与历史、首次改动前原文备份、幂等收据、拒绝与外部编辑冲突、跨路径/内容/会话复用审批失败、会话删除阻断、父目录替换阻断、停止取消及重新发起、真实 Host 位置和无需预授权的只读访问、旧本地审批失效、系统/内部/隐藏目录及链接保护、禁止文本伪装二进制格式。

## 页面与磁盘核对

隔离页面夹具 `127.0.0.1:5178`：直接发送“本地文件测试：修改，把包装需求保存到原来的文件位置”，未添加任何目录。页面显示“是否允许修改此文件？”及临时文档的完整绝对路径，展开后显示原文和拟写入文本。批准前磁盘仍为客户原文，点击“批准此次写入”后磁盘内容改变。

390 × 844 窄屏直接发起删除，显示“是否允许删除此文件？”；长路径正常换行，文档宽度等于视口宽度 390，没有横向溢出。点击拒绝后磁盘文件及内容仍保留。页面不存在“授权此目录”入口。

夹具进程已结束、临时数据已清理，用户原有服务未重启。采用固定 Provider 的验收证明工具和审批闭环，不代表真实模型在所有自然语言指令下都会选择正确工具。真实模型配置需另行 Online Eval。

## 生效和现有范围

需重启 Blackx 后端并刷新页面，旧进程不会自动加载权限实现。当前直接编辑限于现有目录中的 UTF-8 文本（128 KiB）；目录创建、目录删除和二进制编辑未新增。本机并发及崩溃恢复限制见 ADR-0013。
