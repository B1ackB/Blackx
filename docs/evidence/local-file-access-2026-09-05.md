# 真实本地文件权限验收（2026-09-05）

> 历史记录：目录预授权交互已由 [ADR-0013](../adr/0013-just-in-time-file-approval.md) 替代。当前使用 Agent 发起的单次文件操作审批。

本次按用户澄清修正了上一版范围：Agent 可以操作用户授权目录中的真实磁盘文件，所有新建、修改和删除均需逐次人工审批。旧会话文件及备份同样位于本机，返回真实快照路径，不再声称“虚拟区、不在电脑上”。

## 验证

- `npm run check`：44 个测试文件、204 项测试通过，类型检查与 Vite 构建通过；默认跳过 15 项需显式启用的原生专项测试。
- `npm run eval:product`：隔离临时目录与固定本地 Anthropic Provider，走真实 HTTP、Core Loop、Tool、用户审批 API 和操作系统文件系统。覆盖目录未授权拒绝、用户授权、所有新建等待审批、原路径实际写入、用户外部修改后的备份、实际删除与原文恢复读取、撤销目录权限。既有 PDF 原生解析、业务审批/导出、取消及会话删除回归继续通过。
- 文件专项单测：实际读写删除、原文件首次修改前备份、拒绝后不动文件、审批后外部修改冲突、撤销/重新授权不复用旧审批、跨会话与删除会话隔离、目录/最终文件符号链接、硬链接检查、内部目录/隐藏路径保护，以及禁止用纯文本伪造 PDF 等格式。原有幂等、历史和取消回归保留。

## 页面与磁盘交叉验收

通过 `npm run dev:fixture` 创建临时 `user-documents/客户包装需求.md`。在桌面界面填写目录并授权、浏览文件、查看原文、点击“交给 Agent”；发起修改后，审批卡展示真实绝对路径和修改前后内容。此时从命令行读取同一路径仍是原文；点击“批准此次写入”后再次读取，磁盘内容确实已更新。

390 × 844 手机宽度下验证真实路径审批和删除入口，无横向或整页多余滚动。测试使用临时文件，不修改用户原始文档；验收服务和临时数据结束后清理。

## 边界

这是本地工程证据，模型响应来自固定测试 Provider，不代表真实模型选工具的稳定性评估。当前支持 UTF-8 普通文本文件（128 KiB），不提供二进制文档编辑或递归目录删除；本地目录仅在用户主动授权后可访问。单 Host、外部编辑竞争窗口及 `executing/unknown` 崩溃恢复限制见 [ADR-0012](../adr/0012-approved-local-file-access.md)。
