# 本地产品补全：Plan 交接、本机发行与故障保障

日期：2026-09-13

环境：本机 macOS，Node 24；模型为本地固定 Provider，无真实员工和企业素材。

## 已实现

- 无聊天消息的 Plan 会话可以将最新已完成计划导入需求单；导入检查版本、确认和来源快照。
- 通过原有 Requirement Worker 提取候选；事实仍需逐项确认，Artifact 版本与交付审批继续独立。
- 增加六类包装补充字段，已填补充字段未确认时阻止审批；旧七字段基线继续通过。
- Markdown/HTML/JSON 导出按 Artifact 输入版本保留来源计划，界面区分 Plan 报告、模型报告与人工核对。
- `npm run doctor` 无模型请求地检查本地依赖、解析器和配置；`npm start` 提供统一启动别名。
- 默认数据根目录配置、Host/维护互斥、标准布局停机备份、哈希/SQLite 检查及恢复到新目录。
- 提供虚构咖啡袋资料、冲突资料及未填写的真实用户验证表。
- 图形化模型配置：私密文件、权限 0600、版本冲突拒绝、凭据掩码和清除、保存后重启生效。
- Plan 任务自动名称、自定义重命名、名称/摘要/完整目标检索；独立元数据不改变 Session 或 Plan 审批版本。
- macOS 发行目录、压缩包、摘要、启动器与生产静态资源服务；首次安装锁定依赖。
- 原生 Supervisor：CPU/文件大小/描述符内核限制，RSS/进程数/目录采样限制；Host SIGKILL 后清理进程组。
- 输入副本所有者清理、死进程锁恢复和审计、布局版本 1 兼容标记及未知版本拒绝。

## 保留边界

- 固定 Provider 验证编排，不验证真实模型字段提取、矛盾识别或工时收益；冲突资料只提供待人工/真实模型执行的验收预期。
- 当前有 macOS 本地发行目录和图形配置，但没有签名公证、自动升级或干净企业设备验收；首次安装需要 Node 和联网安装依赖。
- 自动备份仅支持标准目录布局，单文件最多 256 MiB；不包含私有配置、外部原文件，不提供加密或云备份。
- 恢复旧快照不能撤销快照之后的外部副作用，启动前须核对任务与定时状态。强制退出遗留锁须按操作指南处理。
- 原生 RSS/进程数预算为 20 ms 采样，允许短时超调；只验证登记解析器的进程组，未证明任意代码脱离进程组、Supervisor 自身被强杀、磁盘损坏等全部故障组合。未来实际 Schema 转换仍须专门迁移，完整 M3 Gate 未关闭。
- 真实包装品类规则、真实用户接受程度、持续使用与付费意愿均待补，不以本记录关闭。
