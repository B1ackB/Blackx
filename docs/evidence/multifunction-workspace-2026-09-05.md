# 右侧多功能工作区验收（2026-09-05）

## 实现

右侧共用可折叠面板，以需求单、模型调用、文件三个页签切换，支持键盘左右键及 Home/End。需求单原有事实确认、版本、审批和导出保留。模型页可切换当前会话与当前需求单工作流的统计；文件页按需展开目录树、打开真实文本或会话快照、刷新内容、把路径放入聊天草稿。切换页签保留文件预览；切换会话清空前一个会话的预览和请求数据。

模型监控位于 Enterprise Runtime Adapter，用 scoped Provider 包装器观察实际 generate/count_tokens 尝试，Core Loop 和权限控制无需改变。Anthropic Provider 额外返回白名单元数据，记录不包含 Prompt、回复正文、密钥或上游错误消息。模型生成、Token Count、成功、失败、取消、中断独立显示；延迟包含该 Provider 操作耗时。缓存缺失与零值分开处理，命中率按 Token 加权计算，显示缓存字段覆盖率。

记录按 tenant/workspace/run 持久化到 Agent 状态目录的 model-calls 子目录；保留最近 200 次，明确截断与启用时间边界。重启后未结束调用显示中断，已删除会话拒绝读取；不补造历史调用或失败请求的 Token 用量，不代表厂商账单。并发存储沿用单 Host 同步更新假设，不是多进程数据库。

## 验证

- `npm run check`：45 个测试文件、213 项测试通过；15 项需要显式启用的原生专项跳过，TypeScript 与 Vite 构建通过。
- `npm run eval:offline`、`eval:m1`、`eval:m2` 通过，M2 为 10 个包装案例。
- `npm run eval:product`：固定本地 Provider 与真实 HTTP、Core、文件系统、原生 PDF 解析。验证模型记录和 Token Count 独立、当前会话/需求单记录隔离、缓存 25% 的数值口径、未认证/伪造身份阻断、取消状态、删除会话后模型统计不可访问，以及原有文件新建修改删除审批与业务交付回归。
- 模型统计专项覆盖持久化恢复、scope 隔离、进行中状态、429 脱敏错误、取消、Host 重启中断投影、缓存未报告与零值、加权比例及 200 条保留上限。
- 浏览器 1280px 和 390px 验收：三个页签互斥可见；模型页显示 local-fixture、5 次生成、5 次 Token Count、25.0% 缓存命中率；数值与测试响应一致。文件树展开子目录、打开客户包装需求原文、交给 Agent 写入草稿均成功；切换模型/文件页签后仍保留预览。390px 文件路径正常换行，文档宽度等于视口宽度，无横向溢出。新建会话后模型调用次数为 0，旧文件预览清空。页面测试服务与临时数据已清理，用户当前主服务未重启。

以上为固定 Provider 的离线集成和页面证据，不代表真实模型网络、缓存收益或生产服务质量。更新需重启 Blackx 后端并刷新页面；文本预览保持 UTF-8、128 KiB 限制，未增加二进制编辑权限。
