# 包装产品范围验收 · 2026-09-05

当前产品范围遵循 [ADR-0010](../adr/0010-packaging-product-focus.md)：仅面向包装行业。

- 页面标题、欢迎语、示例、需求字段和模型指令已聚焦包装；移除行业选择、家具示例和安装字段。
- 新请求、模型输出和 Fact API 不再接受家具行业或家具专属字段。包装保留内部 `print` 标识，行业来源记录为固定 Domain 配置。
- 旧非包装 Run 返回只读说明；禁止重新生成、改写 Fact、审批和当前包装导出。旧任务到达 Worker 时不可重试地停止，保留原始事实、版本和审计；支持取消旧任务及删除会话。包装指标排除旧行业数据。
- 固定评测升级为 `blackx-m2-packaging-workflow-baseline-v3`：10 个包装任务，4 个进入 `passed`，6 个保留 `needs_input`，不把旧跨行业评测冒充当前基线。

验证结果：

| 检查 | 结果 |
| --- | --- |
| `npm run check` | 42 个测试文件、190 项测试通过；15 项原生环境条件测试跳过；类型检查与生产构建通过 |
| `npm run eval:m2` | 包装 v3 基线 10/10 通过 |
| `npm run eval:product` | 本地固定 Provider、实际 Host HTTP、原生 PDF 解析、需求单审批/导出及删除闭环通过 |
| 浏览器 | 包装需求单显示 7 个包装标准字段；无家具入口、行业选择；纸盒示例正确填写草稿；390px 下无横向溢出 |
| 数据边界 | 旧行业不可转换或写入，旧 Worker 无业务状态提交，取消旧任务仍可用；均有离线回归 |

验收只使用临时会话及资料，没有修改真实用户业务记录。上述固定 Provider 与浏览器检查不代表真实包装用户走查或厂商 Online Eval。已有本地 Host 需重启、浏览器需刷新，才能加载更新后的接口与产品指令。
